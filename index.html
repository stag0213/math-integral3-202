線分 PQ の掃引曲面 — 3次元可視化

A(2,0,0), B(0,2,0), C(0,0,2), D(1,1,0), E(0,0,1) と、P(p,0,0) を表示します。

ドラッグ：回転　／　ホイール：拡大・縮小　／　右ドラッグ：平行移動

点 P と線分 PQ

P(1.00, 0, 0)　Q(0, 1.00, 1.00)
R = (1−t)P + tQ。t を動かして、線分上の点を確認できます。

表示設定

パラメータ表示

P = (p, 0, 0)
Q = (0, p, 2−p)
R = (p(1−t), pt, (2−p)t)
0 ≤ p ≤ 2,　0 ≤ t ≤ 1

p を変化させたときの線分 PQ の集合を、パラメータ曲面として描画します。これは内部を塗りつぶした立体ではなく、2次元の掃引曲面です。
